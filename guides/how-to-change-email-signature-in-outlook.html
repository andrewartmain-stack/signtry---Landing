How to change your email signature in Outlook

Changing your email signature in Outlook takes under a minute once you know where the setting lives, and it lives somewhere different in every version. Here is how to change or edit your signature in new Outlook, classic Outlook, Outlook on the web, Outlook for Mac and the mobile app, and what to do when the old one refuses to go away.

Updated October 28, 2026 · 7 min read · By the SignTry team

Quick answer: In new Outlook and Outlook on the web, select Settings → Accounts → Signatures, click the edit button next to your signature, make your changes and select Save. In classic Outlook for Windows, go to File → Options → Mail → Signatures, pick the signature, edit it in the Edit signature box and select OK.

How to change your signature in new Outlook and Outlook on the web

New Outlook for Windows, Outlook on the web and Outlook.com share the same settings page, so these steps work in all three.

  1. Select the Settings gear at the top right.
  2. Go to Accounts → Signatures.
  3. If you have more than one email account, pick the right one at the top of the page.
  4. Select the edit (pencil) button next to the signature you want to change.
  5. Change the text, links or image in the editor, then select Save.

To replace a signature completely, it is often faster to paste a new one over the old text than to edit line by line. A signature built in the free email signature generator pastes in with its layout, photo and links intact.

Using both Outlook on the web and the Outlook desktop app with a personal Microsoft account? Microsoft notes you may need to set up the signature in both, so check each one after you change it.

How to change your signature in classic Outlook for Windows

  1. Select File → Options → Mail.
  2. Select Signatures….
  3. Under Select signature to edit, click the signature you want to change.
  4. Make your changes in the Edit signature box. Use the image button to swap a logo or photo.
  5. Select Save, then OK.

Shortcut: while writing an email, select Message → Signature → Signatures… to open the same window without leaving the draft.

Classic Outlook can store signatures on the computer itself. If you use Outlook on two PCs, a change on one may not appear on the other, so open the Signatures window on each machine and check.

How to change your signature in Outlook for Mac

  1. Open Outlook and choose Outlook → Settings in the menu bar.
  2. Select Signatures.
  3. Pick the signature in the list and edit it on the right.
  4. Close the window. Outlook for Mac saves the change automatically.

Under Default signatures in the same window you choose which signature each account uses for new messages and for replies.

How to change your signature in the Outlook app on iPhone and Android

  1. Open the Outlook app and tap your profile picture at the top left.
  2. Tap the Settings gear.
  3. Tap Signature (in some versions it sits under Mail).
  4. Edit the text. Turn on Per account signature if each address needs its own.

The app keeps its own signature, separate from desktop and web, and it is built for plain text and links. If your phone still says “Get Outlook for iOS”, this is where you replace it. Using Apple Mail instead? See how to change your email signature on iPhone.

How to change which signature Outlook uses

Sometimes the signature is fine and Outlook simply picks the wrong one. New messages and replies are separate settings:

  • New Outlook and the web: on Settings → Accounts → Signatures, set For new messages and For replies and forwards, then select Save.
  • Classic Outlook: in the Signatures window, under Choose default signature, pick the account and set New messages and Replies/forwards.

A common setup is a full signature for new emails and a two-line version for replies, so a long thread doesn't repeat your logo twenty times.

How to change your signature for one email only

No need to touch the settings for a one-off. Open the draft, select Signature on the Message (or Insert) tab and pick a different saved signature. Outlook swaps it in that email only. If you send the same email often, save it as a template too: here is how to create an email template in Outlook.

Changed your signature but the old one still shows up?

You saved the change, sent a test, and there it is: last year's job title. These are the usual causes, roughly in order of how often they bite:

  • You edited a different account. Each account has its own signatures and defaults. Check the account at the top of the Signatures page matches the one in your From field.
  • The draft was already open. Outlook adds the signature when the message is created. Close the draft and start a new one.
  • Another device or app still has the old one. The mobile app, Outlook for Mac and classic Outlook on a second PC can each keep their own copy. Microsoft's roaming signatures store signatures in the mailbox for Microsoft 365 and Outlook.com accounts in recent Outlook for Windows builds; POP, IMAP and on-premises Exchange accounts do not roam.
  • Your company adds the signature. If IT adds signatures on the mail server, recipients see that one no matter what you set in Outlook, and you won't see it in Sent Items. Ask IT to update it.
  • You are looking at an old thread. Earlier replies keep the signature they were sent with. Only new messages get the new one.

Frequently asked questions

How do I edit my signature in Outlook?

In new Outlook or Outlook on the web, select Settings, Accounts, Signatures, click the edit button next to the signature and select Save when you are done. In classic Outlook, go to File, Options, Mail, Signatures, select the signature and edit it in the Edit signature box.

Why won’t my new signature show up in Outlook?

Usually the change was made on a different account, the draft was opened before the change, or another device still uses its own copy. If your company adds signatures on the mail server, only IT can change what recipients see.

How do I change my signature in Outlook 365?

Outlook in Microsoft 365 uses the new Outlook settings: Settings, Accounts, Signatures. Edit the signature, set it as the default for new messages and replies, and select Save.

Can I use a different signature for replies?

Yes. Set one signature for new messages and another, usually shorter, for replies and forwards. Both settings are on the same Signatures page.

How do I change my Outlook signature on my phone?

In the Outlook app, tap your profile picture, the Settings gear and then Signature. The app signature is separate from the desktop and web signature, so change it there too.
