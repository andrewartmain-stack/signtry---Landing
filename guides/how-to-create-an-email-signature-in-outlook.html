How to make an email signature in Outlook

Here is how to make an email signature in Outlook in under two minutes, whichever version you use: new Outlook for Windows, classic Outlook, Outlook on the web, Outlook for Mac or the Outlook mobile app. You will also learn how to change, edit and add a logo to your Outlook signature.

Updated October 28, 2026 · 7 min read · By the SignTry team

Quick answer: In new Outlook and Outlook on the web, go to Settings → Account → Signatures, select + New signature, type or paste your signature, choose it as the default for new messages and replies, then click Save. In classic Outlook for Windows, go to File → Options → Mail → Signatures → New.

How to create an email signature in new Outlook and Outlook on the web

New Outlook for Windows, Outlook on the web and Outlook.com share the same settings, and in Microsoft 365 your signature can follow you between them.

  1. Select the Settings gear icon at the top right.
  2. Go to Account → Signatures.
  3. Select + New signature and give it a name, such as “Work”.
  4. Type your signature in the editor, or paste one you made in SignTry. Use the toolbar for bold, colors, links and images.
  5. Under Select default signatures, choose it for new messages and for replies and forwards.
  6. Select Save.

If you have more than one email account in Outlook, pick the right account at the top of the Signatures page before you choose the defaults.

How to create an email signature in classic Outlook for Windows

  1. Select File → Options → Mail.
  2. Select Signatures….
  3. On the E-mail Signature tab, select New, type a name and select OK.
  4. Type or paste your signature in the Edit signature box.
  5. Under Choose default signature, pick the email account and set the signature for New messages and Replies/forwards.
  6. Select OK.

Shortcut: when you are writing an email, select Message → Signature → Signatures… to open the same window.

How to create an email signature in Outlook for Mac

  1. Open Outlook and choose Outlook → Settings in the menu bar.
  2. Select Signatures.
  3. Select +, name the signature and type or paste it in the editor.
  4. Save, then under Default signatures choose it for new messages and replies for each account.

How to add a signature in Outlook on iPhone and Android

  1. Open the Outlook app and tap your profile picture at the top left.
  2. Tap the Settings gear.
  3. Tap Signature.
  4. Replace the default text with your signature. Turn on Per account signature if you want a different one for each account.

The mobile app keeps signatures simple. Text and links work well; logos and complex layouts are best set up on desktop or web. Mobile and desktop signatures are separate, so set up both.

How to change or edit your email signature in Outlook

To change your email signature in Outlook, go back to the same place you created it: Settings → Account → Signatures in new Outlook and on the web, or File → Options → Mail → Signatures in classic Outlook. Select the signature from the list, edit it, and save. To update a new job title or phone number, edit the existing signature rather than creating a new one, so your default settings stay the same.

How to add a logo or image to your Outlook signature

In the signature editor, place your cursor where the image should go and use the image button in the toolbar (classic Outlook has an Insert Picture icon). Keep images small: a logo around 150–200 pixels wide and a headshot around 100 pixels square look sharp without making emails heavy. Our email signature size guide has exact dimensions.

Images inserted from your computer are embedded in every email, and some recipients see them as attachments. Signatures made in SignTry use hosted images instead, which display more reliably.

Outlook signature not showing? Common fixes

  • No default is set. Choose the signature for new messages and for replies; they are separate settings.
  • Wrong account. Each account has its own defaults. Check you set it on the account you send from.
  • Different device. Classic Outlook stores signatures on the computer, so a signature made on your laptop will not appear on your desktop. Set it up on each device, or use new Outlook or the web where signatures can roam.
  • Plain text emails. If you send in plain text format, formatting and images are removed. Switch to HTML format.

Frequently asked questions

How do I change my email signature in Outlook?

In new Outlook or Outlook on the web, go to Settings, Account, Signatures, select your signature, edit it and click Save. In classic Outlook, go to File, Options, Mail, Signatures, select the signature and edit it in the Edit signature box.

How do I create a signature in Outlook 365?

Outlook in Microsoft 365 uses the new Outlook settings: Settings, Account, Signatures, then + New signature. Type or paste your signature, set your defaults and click Save.

Why is my signature not showing in Outlook?

Usually because no default signature is set for new messages or for replies, or it is set on a different account. In classic Outlook, signatures are also stored per computer.

Can I have more than one signature in Outlook?

Yes. Create as many as you like, for example a full one for new emails and a short one for replies, and choose a default for each.

What size should my Outlook signature image be?

A logo around 150–200 pixels wide and a headshot around 100 pixels square work well. Keep the whole signature under 600 pixels wide. See our email signature size guide.
